# Full stack development - University of Helsinki, Finland open coursework

### Modules in this course

- part0: first look into how web development works
- part1: basic of reactjs
- part2: REST API, axios, error handling, promises, state management, component lifecycle,...

### Room for improvements

- Change from Javascript to Typescript (to avoid typing ambiguity) for better readability and debugging
- Split helper functions into a separate directory `utils`
- Better readability can be achieved with separating reusable codes into functions
- Gradually change from small API solution to a more customizable one (e.g. Go, Node.js)

**However, for the sake of a learning course, I will try to deliver fastest results, with a suitable amount of works in refactoring code for further development**
